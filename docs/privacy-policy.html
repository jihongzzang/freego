개인정보처리방침

최종 업데이트: 2025년 1월 15일

1. 개요

본 애플리케이션(이하 "앱")은 사용자의 개인정보를 소중히 여기며, 개인정보를 수집하지 않습니다.

2. 수집하는 정보

본 앱은 어떠한 개인정보도 수집하지 않습니다.

  • 계정 정보 수집 없음 (이메일, 비밀번호 등)
  • 외부 서버로 데이터 전송 없음
  • 제3자와 정보 공유 없음
  • 분석 도구 사용 없음

3. 데이터 저장

모든 앱 데이터는 사용자의 기기에만 저장됩니다:

  • 냉장고 재고 목록
  • 장보기 목록
  • 사용자 설정

이러한 데이터는 사용자의 기기를 벗어나지 않으며, 앱을 삭제하면 모든 데이터가 함께 삭제됩니다.

4. 알림 기능

본 앱은 로컬 알림만 사용합니다:

  • 유통기한 임박 알림
  • 기기에서 직접 예약되는 알림
  • 외부 서버를 사용하지 않음
  • 푸시 알림 서버 미사용

5. 데이터 보안

모든 데이터가 기기 내부에만 저장되므로, 데이터 보안은 기기의 보안 설정에 의해 보호됩니다.

6. 어린이 개인정보

본 앱은 개인정보를 수집하지 않으므로, 모든 연령대의 사용자가 안전하게 사용할 수 있습니다.

7. 개인정보처리방침 변경

본 개인정보처리방침은 필요에 따라 업데이트될 수 있으며, 변경 시 앱 내에서 공지됩니다.
