# 법적 문서

이 폴더에는 앱스토어 제출을 위한 필수 문서들이 포함되어 있습니다.

## 파일 목록
- `privacy-policy.html` - 개인정보처리방침
- `terms-of-service.html` - 이용약관

## GitHub Pages로 호스팅하기

1. GitHub 저장소 생성 (아직 없다면)
2. 이 폴더를 커밋하고 푸시
3. GitHub 저장소 > Settings > Pages
4. Source를 "Deploy from a branch" 선택
5. Branch를 "main" (또는 "master"), 폴더를 "/docs" 선택
6. Save 클릭

몇 분 후 다음 URL로 접속 가능:
- 개인정보처리방침: `https://[username].github.io/[repo-name]/privacy-policy.html`
- 이용약관: `https://[username].github.io/[repo-name]/terms-of-service.html`

## 앱스토어 제출 시
위에서 생성된 URL을 앱스토어 제출 양식에 입력하세요.

## 수정 사항
- `your-email@example.com`을 실제 이메일로 변경하세요
- 앱 이름이 확정되면 문서에 반영하세요
