개인정보처리방침

최종 업데이트: 2025년 11월 16일

요약: 본 앱은 어떠한 개인정보도 수집하지 않으며, 모든 데이터는 사용자의 기기에만 저장됩니다.

1. 개인정보 수집

냉장고 재고관리 앱(이하 "프리고 앱")은 사용자의 개인정보를 일체 수집하지 않습니다.

  • 회원가입 불필요 - 계정, 이메일, 비밀번호 등 개인 식별 정보 미수집
  • 분석 도구 미사용 - Google Analytics, Firebase Analytics 등 사용하지 않음
  • 제3자 서비스 미연동 - 광고, SNS 로그인 등 외부 서비스 연동 없음
  • 네트워크 통신 없음 - 서버로 데이터를 전송하지 않음

2. 데이터 저장 방식

본 앱은 다음 데이터를 사용자의 기기 내부에만 저장합니다:

  • 식재료 정보: 이름, 카테고리, 보관 위치, 유통기한, 수량, 이모지, 메모
  • 장보기 목록: 구매할 항목, 카테고리, 메모
  • 앱 설정: 알림 설정, 사용자 커스터마이징 옵션
  • 도전과제 진행상황: 사용 통계 및 달성 기록

이러한 데이터는 기기의 로컬 저장소(AsyncStorage)에 암호화되어 저장되며, 외부로 전송되지 않습니다.

3. 데이터 삭제

사용자는 언제든지 데이터를 완전히 삭제할 수 있습니다:

  • 앱 내에서 개별 항목 삭제
  • 앱 삭제 시 모든 데이터가 기기에서 영구 삭제됨
  • 기기 설정에서 앱 데이터 삭제

중요: 데이터는 기기에만 저장되므로, 앱 삭제 시 복구가 불가능합니다. 필요한 경우 사용자가 직접 백업해야 합니다.

4. 알림 기능

본 앱은 로컬 푸시 알림만 사용합니다:

  • 유통기한 임박 알림 (사용자가 설정한 시간에 기기에서 직접 발송)
  • 외부 푸시 알림 서버 미사용
  • 알림 내용이 외부로 전송되지 않음
  • 사용자가 설정에서 알림을 언제든지 비활성화 가능

5. 권한 요청

본 앱은 다음의 권한만 요청합니다:

  • 알림 권한: 유통기한 알림을 전송하기 위함

위 권한은 앱의 핵심 기능 제공을 위해서만 사용되며, 다른 목적으로 사용되지 않습니다.

6. 데이터 보안

모든 데이터가 사용자의 기기 내부에만 저장되므로, 데이터 보안은 기기의 보안 설정(암호, 생체인식 등)에 의존합니다. 사용자는 기기 보안을 철저히 관리할 책임이 있습니다.

7. 어린이 개인정보

본 앱은 개인정보를 수집하지 않으므로, 13세 미만 어린이를 포함한 모든 연령대의 사용자가 안전하게 사용할 수 있습니다.

8. 제3자 정보 공유

본 앱은 어떠한 정보도 제3자와 공유하지 않습니다.

  • 광고 네트워크 미사용
  • 분석 서비스 미사용
  • 클라우드 백업 서비스 미사용
  • 소셜 미디어 연동 없음

9. 개인정보처리방침 변경

본 개인정보처리방침은 관련 법령 및 앱 기능 변경에 따라 업데이트될 수 있습니다. 변경 시 앱 내 공지 또는 업데이트 노트를 통해 안내하며, 중요한 변경사항은 사전에 공지합니다.

10. 사용자 권리

사용자는 다음의 권리를 보유합니다:

  • 언제든지 앱 내 데이터를 확인, 수정, 삭제할 수 있는 권리
  • 개인정보처리방침에 대해 문의할 권리
  • 알림 기능을 비활성화할 권리
  • 언제든지 앱 사용을 중단할 권리
