이용약관

최종 업데이트: 2025년 1월 15일

1. 서비스 이용

본 애플리케이션(이하 "앱")을 다운로드하거나 사용함으로써 귀하는 본 이용약관에 동의하게 됩니다.

2. 서비스 설명

본 앱은 다음과 같은 기능을 제공합니다:

  • 냉장고 재고 관리
  • 장보기 목록 관리
  • 유통기한 알림
  • 카테고리별 정리

3. 사용자 책임

사용자는 다음을 준수해야 합니다:

  • 앱을 합법적인 목적으로만 사용
  • 앱의 기능을 남용하거나 방해하지 않음
  • 다른 사용자에게 해를 끼치는 행위 금지

4. 데이터 백업

모든 데이터는 사용자의 기기에만 저장됩니다. 사용자는 자신의 데이터를 백업할 책임이 있으며, 앱 삭제 또는 기기 문제로 인한 데이터 손실에 대해 개발자는 책임지지 않습니다.

5. 서비스 제공

본 앱은 "있는 그대로" 제공됩니다:

  • 서비스의 정확성, 완전성, 신뢰성을 보장하지 않음
  • 언제든지 예고 없이 서비스를 변경하거나 중단할 수 있음
  • 앱 사용으로 인한 직간접적 손해에 대해 책임지지 않음

6. 지적 재산권

본 앱과 관련된 모든 콘텐츠, 디자인, 로고는 개발자의 지적 재산입니다. 무단 복제, 배포, 수정을 금지합니다.

7. 면책 조항

개발자는 다음에 대해 책임지지 않습니다:

  • 앱 사용 중 발생한 데이터 손실
  • 기기 호환성 문제
  • 사용자의 잘못된 정보 입력으로 인한 문제
  • 제3자 서비스와의 통합 문제

8. 약관 변경

개발자는 필요에 따라 본 이용약관을 변경할 수 있으며, 변경 시 앱 내에서 공지됩니다. 변경된 약관은 공지 후 즉시 효력이 발생합니다.

9. 계정 종료

사용자는 언제든지 앱을 삭제하여 서비스 이용을 중단할 수 있습니다. 앱 삭제 시 모든 로컬 데이터가 삭제됩니다.

10. 준거법
