# 냉장고 재고관리 앱

음식물 쓰레기를 줄이고 현명한 소비를 위한 냉장고 관리 애플리케이션입니다.

## 시작하기

### 필수 요구사항

- Node.js (v22.20.0)
- npm 또는 yarn
- Expo Go 앱 (iOS/Android)

### 설치 방법

1. 의존성 패키지 설치:

```bash
npm install
```

2. 개발 서버 실행:

```bash
npm run dev
```

3. Expo Go로 실행:
   - iOS: App Store에서 "Expo Go" 다운로드
   - Android: Google Play에서 "Expo Go" 다운로드
   - QR 코드를 스캔하여 앱 실행
